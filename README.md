# CheapFly.ca

**Canada's cheap-flight playbook** — free deal alerts (lead generation), a deal-threshold price watch for 80+ routes, one-click multi-engine flight search, 50 in-depth guides and city pages, and 9 free tools. Built with Jekyll for the **free GitHub Pages plan** (`main` branch) and ready for Google AdSense.

- Live (GitHub Pages): `https://webworksa1.github.io/cheapfly-ca/` → once DNS is connected: **https://cheapfly.ca**

## Owner settings — edit `_config.yml`

Everything a non-developer changes lives in `_config.yml`:

- `adsense.client` — already `ca-pub-6620975821265271`. After approval, optionally paste manual ad-unit slot IDs into `adsense.slots` (top, incontent, sidebar, bottom). Auto ads work without them.
- `analytics.ga4` — paste a GA4 measurement ID (e.g. `G-XXXX`) to enable analytics.
- `contact_cta_url` — the top-bar business link (`https://web.works/contact`).
- `forms.alias` — after FormSubmit activation (below), paste the random alias it gives you.
- `donate.paypal / stripe / kofi / buymeacoffee` — paste payment links; buttons appear automatically on `/support/`.
- `social.*` — paste profile URLs; links appear in the footer (and a YouTube subscribe band on `/videos/`).

## Launch checklist (in order)

1. **Enable GitHub Pages:** repo **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.** Wait 1–2 minutes and open `https://webworksa1.github.io/cheapfly-ca/`.
2. **Connect cheapfly.ca:** at your domain registrar, create DNS records:
   - `A` @ → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `AAAA` @ → `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`
   - `CNAME` www → `webworksa1.github.io`
   Then **Settings → Pages → Custom domain → `cheapfly.ca` → Save**, and tick **Enforce HTTPS** when it becomes available. No code change is needed — internal links adapt automatically.
3. **Activate the forms:** submit any form on the live site once (for example the contact form). FormSubmit emails the owner inbox an activation link — click it. Forms then deliver to the inbox. In the FormSubmit confirmation you'll receive a random alias; paste it into `forms.alias` in `_config.yml` so even the network request no longer carries the address.
4. **Brand images (1 minute):** upload the five PNGs (`og-image.png`, `favicon-32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`) to `assets/img/` via **Add file → Upload files** — the templates switch them on automatically. Or automate it with the workflow template in `_branding/` (see `_branding/README.md`).
5. **Search Console:** add `https://cheapfly.ca` in Google Search Console, verify via DNS, and submit `https://cheapfly.ca/sitemap.xml`. Do the same in Bing Webmaster Tools.
6. **AdSense:** after the site has been live on cheapfly.ca for about 1–2 weeks and pages show as indexed, add the site in AdSense (the script and `ads.txt` are already in place). In **AdSense → Privacy & messaging**, enable the European regulations (GDPR) message so EEA/UK visitors see a Google-certified consent banner.
7. **Email delivery of alerts:** create a free account with an email service provider (MailerLite, Beehiiv or Brevo). Import subscribers from form emails and send the weekly digest. *Deal alerts are the product — send them consistently.*
8. **Payments:** create a PayPal donate button or a Stripe Payment Link and paste it into `donate.*`.

## Updating content

- **Add a guide:** create `_guides/my-new-guide.md` with front matter like the existing guides (title, description, category, icon, date, updated, faq). It appears on `/guides/`, in the sitemap and the RSS feed automatically.
- **Edit the price watch:** edit `_data/routes.yml` (one block per route). Add `alert: "..."` to show a warning on a route.
- **Add YouTube videos:** append to `_data/videos.yml`:
  ```yaml
  - id: "VIDEO_ID"          # the 11 characters after watch?v=
    title: "Exact video title"
    channel: "Channel name"
    category: "Cheap flight hacks"
    guide: "how-to-find-cheap-flights-from-canada"   # optional: also shows on that guide
  ```
  Videos then appear on `/videos/` (with topic filters) and on the matching guide.
- **Update passenger-rights amounts or carry-on sizes:** edit `_data/appr.yml` or `_data/carryon.yml` — the tools update automatically.
